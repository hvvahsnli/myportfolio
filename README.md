# 🚀 Portfolio Website

This project is my personal **Portfolio Website** built using React and JavaScript. It showcases my skills, work samples, and contact information.

## 🛠️ Technologies Used

- ⚛️ React (Functional Components & Hooks)  
- 🟨 JavaScript (ES6+)  
- 🎨 CSS3 
- 🌐 React Router  

## ✨ Features

- 🖥️ Modern and clean user interface  
- 📱 Responsive design with mobile and desktop support  
- 📂 Visual presentation of portfolio projects
